### 🚀 What I build

Real-time operations work runs on decisions made in seconds — who is available,
which queue is burning, what a customer needs to hear next. My projects turn
those recurring decisions into tools: dashboards that read the data already on
screen, generators that write the message you were about to type, and planners
that take the guesswork out of the day.

Everything here is built to survive a real shift: no setup ceremonies, no
training decks, and it has to keep working when the queue spikes.
